# Futuristic Glassmorphism Image Gallery

A modern and responsive Image Gallery built using HTML, CSS, and Vanilla JavaScript.  
This project features a futuristic glassmorphism UI, animated particles background, category filters, smooth hover effects, and an interactive lightbox experience.

## Features
- Responsive image gallery layout
- Glassmorphism design
- Animated particles background using Canvas
- Category filtering system
- Interactive lightbox preview
- Next / Previous image navigation
- Smooth hover zoom animations
- Fully responsive design
- Modern gradient neon UI

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Canvas API
